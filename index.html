PROBLEM AND APPROACH

From spreadsheet workflow to a web application

I started with an Excel tracker to make a fragmented internship search easier to manage. I then translated the workflow into a browser-based dashboard with a public fictional demo and a separate authenticated workspace.

DATA QUALITY CONTROLS

Designed to reduce avoidable errors

  • Required fields and controlled status values
  • Duplicate checks before records are added
  • Source-link and last-verified fields
  • Archive rules that preserve history
  • Human review before a posting is treated as current

LIMITATIONS AND OWNERSHIP

What this project does—and does not—claim

The demo uses fictional data and browser storage. The account workspace is a beta, not a claim of production certification or fully autonomous real-time job scraping. I defined the requirements, rules, and privacy boundaries; used AI-assisted coding tools; and reviewed, tested, and refined the implementation.
