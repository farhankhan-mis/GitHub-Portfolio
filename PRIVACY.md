# Privacy

The Public Opportunity Catalog does not require an account and does not transmit application history, résumés, notes, contacts, or other private career data to this repository or its public catalog service.

Saved opportunities, application statuses, and notes are stored only in the visitor's browser using local storage. They are specific to that browser profile, do not sync between devices, and can be lost if browser storage is cleared. Search terms and filters are not saved. Clicking an Apply link opens the external source site, whose own privacy policy applies.

The catalog contains public metadata about opportunities and organizations. Private tracker data and personal documents remain explicitly prohibited from the repository, public catalog JSON, and Supabase mirror.
